# @hexagen-monaco/gate-lock

A host-wide gate lock: a shared pool of test-runner slots across projects and worktrees on one host, speaking on-disk format 1.

**Status: pre-0.1.** Only `gate-lock --format` and `gate-lock --version` work so far. The full README (usage, exit codes, platform notes) arrives with the `run` subcommand.
